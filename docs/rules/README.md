# docs/rules/ — 運用ルール（カテゴリ別）

実験・提出・環境・git の運用規約。人間・Coding Agent 共通。

| ファイル | 内容 | 読むタイミング |
|---|---|---|
| [experiment.md](experiment.md) | 1実験1ディレクトリ・成果物管理 | 実験を始める前（`/new-exp` が参照） |
| [knowledge.md](knowledge.md) | 知見の記録先と手順 | 実験・調査の結果が出たとき（`/save-knowledge` が参照） |
| [issues.md](issues.md) | 実験の GitHub Issue 運用（1実験1Issue・ラベル・ライフサイクル） | 実験の開始・進行・終了時（`/new-exp`・`/save-knowledge` が参照） |
| [submission.md](submission.md) | 提出規約（承認・ローカルゲート・SUBMIT_LOCK・提出後の推移監視） | 提出前（`/submit-check` が参照） |
| [environment.md](environment.md) | ローカル実行環境（Docker・uv・Windows） | 開発環境を触る前 |
| [external-data.md](external-data.md) | 公開ノートブック・公開コードの利用ポリシー | 公開資産を検討するとき（`/kaggle-notebook-pull` が参照） |
| [kaggle-api.md](kaggle-api.md) | Kaggle API の運用（認証・既知の故障・コマンド集・nvidia-kaggle プラグインとの役割分担） | Kaggle 操作全般 |
| [git.md](git.md) | git 運用（コミット規約・正本の場所） | 常時 |

> 方法論の「教訓」（なぜこのルールがあるか）は `docs/knowledge/findings.md` §4、個別の運用 gotcha は `kaggle-api.md`・`environment.md` を参照。
