# git 運用

- **結果が出るたびにコミット**する（スコア・検証結果をメッセージに含める）。**退行・失敗もコミット**する
  （なぜ戻したかを git log で追えるように）。
- コミットメッセージは `[expNNN] 概要（数値があれば記載）` の形式。docs のみの更新は `[docs]`、環境整備は `[env]`。
  実験コミットは末尾に Issue 番号 `(#N)` を含める（Issue タイムラインへの自動リンク — `docs/rules/issues.md`）。
- 大文字ファイル名・命名規約は `docs/README.md` を参照。
- 大物（モデル重み・リプレイ・データセット等）はコミットしない（`.gitignore` 済み。`docs/rules/experiment.md`）。
- 共通ロジック（`tools/` 等）にテストを追加したら `uv run pytest` を実行してからコミットする。
