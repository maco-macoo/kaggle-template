# exp/ — 実験

1 実験 = 1 ディレクトリ。ID は小文字の接頭辞と 3 桁の連番にする。

- 初期の命名は `eNNN`（`e001`、`e002`、…）。
- 複数人で作業する場合は、開始時にこの節へ担当者と接頭辞の対応を記入し、各接頭辞で採番する。
- 新しい実験は `new-exp` スキルで始める。

| ファイル | 内容 |
| --- | --- |
| `<ID>/README.md` | 実験 1 件の記録（狙い・仕様・再現手順・結果・考察） |
| `<ID>/output/` | 予測結果・モデル重み・ログなどの出力（git 管理外） |
| `README.md`（このファイル） | 実験の一覧と提出履歴 |
| [cv_lb.csv](cv_lb.csv) | 提出ごとの CV と LB。提出履歴と同じ内容を可視化用に持つ |
| [findings.md](findings.md) | 実験をまたぐ知見と現状。作業前に最初に読む |
